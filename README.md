# TALI — homepage prototype

Static, bilingual (Persian RTL default, English LTR via the FA/EN button or `#en`) homepage.
Open `index.html` in a browser. No build step.

## Assets
All images are genuine TALI assets from `../` (photos + logos), resized to WebP in `assets/img/`.
`p5-cut.webp` is a background-removed cut-out of photo 5, pixel-aligned with `p5.webp` so the wordmark sits between them.
No stock or temporary images are used.
